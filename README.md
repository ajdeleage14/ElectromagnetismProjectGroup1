# ElectromagnetismProjectGroup1
Project Overview  

A core focus of electromagnetic theory is the study of electric fields; specifically, how different configurations of stationary charges can induce different electric fields.  

A singular electric charge that will produce an electric field that points radially relative to the charge itself. For a positive charge, the electric field points radially outwards. For a negative charge, the electric field points radially inwards.  

This project contains the code used to solve for the case of a charged ring, when the region of interest for the electric field is above the center of the ring.
